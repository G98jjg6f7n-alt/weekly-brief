## 三、已知限制

1. **中文摄影源缺失**：色影无忌、蜂鸟、摄影之友的 RSS 都已失效，摄影板块目前只有英文源，
   没有 Key 时该板块全是英文。
2. **跨语言重复**：同一事件中英文各报一次时，只有配了 Key 才会被合并；
   纯规则模式下可能重复出现。
3. **GitHub Pages 在部分网络下较慢**：可换 Cloudflare Pages，或直接看本地文件。
4. **云端部署未完成**：需要你的 GitHub 账号和 API Key 才能推上去。

python3 run.py --no-llm --force --no-open   # 无 Key 全量跑一遍（约 60 秒）

./install_schedule.sh                       # 本机每周五 21:00 自动生成
