# 每周新闻周报 · 可行性评估

> 评估时间：2026-10-31｜环境：macOS + Python 3.12（随环境自带）/ Python 3.9（系统）

## 1. 结论

**可行，且成本极低。** 四类兴趣（AI、汽车、数码、摄影）都能找到持续更新的公开 RSS 源，
抓取、去重、聚类、生成排版这条路没有技术障碍。真正需要做取舍的只有三件事：

1. **摘要质量** —— 靠大模型写还是靠规则抽取（决定要不要 API key、要不要联网）。
2. **运行形态** —— 本地网页 / 云端网页 / App（决定"周五晚上怎么看到它"）。
3. **中文源缺口** —— 汽车、摄影两块的中文垂直源偏弱（见下表），需要用英文源翻译补齐。

## 2. 源站实测（2026-10-31 实测，非文档推测）

| 板块 | 可用源 | 状态 | 备注 |
|---|---|---|---|
| AI | 量子位、InfoQ、极客公园、The Verge AI、MIT Tech Review | ✅ | 机器之心 RSS 返回的 XML 格式损坏，需容错解析后可用 |
| 数码 | IT之家(60条)、爱范儿、少数派、9to5Mac(100条)、The Verge、Engadget、cnBeta(150条)、雷峰网 | ✅ | 质量最好、最稳定的一块 |
| 汽车 | Electrek(150条)、InsideEVs、Motor1、Autocar、Car and Driver、The Drive | ✅ | 中文垂直汽车源普遍无 RSS 或已失效 |
| 汽车(中文补位) | 界面新闻、钛媒体、极客公园 | ⚠️ | 综合科技/商业源，需按关键词过滤出汽车内容 |
| 摄影 | PetaPixel、Fstoppers、CanonRumors | ✅ | 中文摄影源（色影无忌/蜂鸟）RSS 已失效 |

**关键发现：**

- 英文源丰富、稳定、更新快；中文源在数码/AI 充足，**汽车与摄影的中文垂直源明显不足**。
  → 建议：中文源直出，英文源自动翻译成中文摘要。
- 各源 RSS 自带的正文长度差异极大：雷峰网单条约 2600 字，9to5Mac / Electrek 只有 100~200 字摘要。
  → 只看 RSS 摘要，写不出有信息量的总结；需要**抓正文**，但要能优雅降级。
- 同一件事会被 5 个源同时报道（实测"苹果智能接入阿里千问"出现在 3 个源）。
  → 必须做**跨源去重聚类**，否则周报全是重复。

## 3. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 某个源改版/挂掉/反爬 | 该板块内容变少 | 每个板块配 3~5 个源，单源失败只降权不报错；源清单可在配置文件里改 |
| RSS 里没有正文 | 摘要空洞 | 抓正文 + 提取失败时自动退回 RSS 摘要，绝不中断生成 |
| 大模型 API 超时/欠费/无 key | 整期生成失败 | 摘要引擎可插拔，失败自动降级为规则摘要，保证"每周一定有东西看" |
| 周五晚上 Mac 不在线 | 没有周报 | 定时任务设置为"错过后开机补跑"，另提供双击即跑入口 |
| 依赖装不上/环境损坏 | 程序跑不起来 | **只用 Python 标准库**，零第三方依赖，不装包、不建虚拟环境 |
| 生成结果残缺 | 看不出来 | 生成后自检：条数、板块完整性、链接可达性、字数，不合格就告警并保留原始数据 |

## 4. 方案对比

| 方案 | 形态 | 优点 | 缺点 | 开发量 |
|---|---|---|---|---|
| **A. 本地网页** | 双击生成自包含 HTML，存本地 | 不依赖服务器；历史可回看；离线可读；最稳 | 需要在 Mac 上跑一次 | 小 |
| **B. 云端网页** | GitHub Actions 定时生成，发布到 Pages | 手机/电脑随时能看，不依赖 Mac 开机 | 需要公开仓库 + API key 放 secrets | 中 |
| **C. 菜单栏 App** | SwiftUI / Tauri 原生应用 | 有 App 的感觉 | 开发成本最高，周报最终还是跳浏览器看 | 大 |
| **D. 邮件周报** | 每周五发到邮箱 | 最省事，手机上直接读 | 排版和图片受限 | 中 |

**推荐：先做 A**（最稳、能立刻用、开发量最小），架构上把"抓取 / 生成"和"展示"解耦，
之后想加 B（云端定时）或 D（邮件推送）只需要换一层外壳，核心逻辑不用重写。

## 5. 最终选型（已实现）

综合你的回答（要炫酷、手机能看、云端定时、UI 简洁、学生预算、英文原文配中文翻译、深度阅读），
最终实现为 **A + B 的组合**：

- **生成端**：Python 标准库流水线，本地和 GitHub Actions 用同一套代码
- **托管端**：GitHub Actions 每周五 21:00（北京时间）定时跑，产物发布到 GitHub Pages
- **摘要**：DeepSeek 大模型逐句生成「英文原句 + 中文翻译」，失败自动降级为规则摘要
- **推送**：Bark / Server 酱 / 自定义 webhook，另可「添加到主屏幕」当 App 用
- **成本**：`deepseek-flash` 错峰价，每周约 0.05 元

实测记录（2026-10-31）：24 个源全部抓取成功，737 篇文章，正文提取成功率 95%，
整期生成 10~45 秒，自检通过。
